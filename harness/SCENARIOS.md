# 네이티브 smoke 시나리오

Jest가 확인할 수 없는 네이티브 동작을 변경했을 때만 관련 시나리오를 실행한다. 각 실행은 사용한 기기, 결과, 실패 로그와 필요한 스크린샷을 남긴다.

## 소셜 로그인 콜백

1. 카카오 로그인을 완료하고 iOS의 `스티켓에서 열겠습니까?` 안내에서 `열기`를 누른다.
2. 앱이 로그인 화면으로 돌아가지 않고 프로필 설정 또는 홈 화면으로 이동하는지 확인한다.

## 티켓 생성

1. 완료된 경기를 선택해 티켓을 만든다.
2. 좌석, 별점, 메모와 음식이 상세 화면에 표시되는지 확인한다.
3. 같은 경기를 다시 저장하면 중복 안내가 표시되는지 확인한다.

## 원본 티켓 OCR

1. 실제 iPhone에서 날짜·구장·좌석이 각각 하나씩 선명한 종이 티켓과 모바일 티켓을 추가해 날짜, 경기와 좌석이 자동으로 채워지는지 확인한다.
2. 예매일과 경기일이 함께 보이는 티켓은 날짜를 자동으로 채우지 않는지 확인한다.
3. 더블헤더 티켓은 해당 날짜의 경기 목록만 보이고 어느 경기도 자동 선택되지 않는지 확인한다.
4. `112블럭 A열 8번`, `2B블럭 G열 8번`처럼 숫자 또는 영문이 섞인 블록명이 원문 그대로 상세 위치에 입력되는지 확인한다.
5. 구장명 없이 두 팀명이 선명한 티켓은 해당 날짜에 일치하는 경기가 하나일 때만 경기가 선택되는지 확인한다.
6. 경기 데이터가 없거나 경기 후보가 여러 개여도 확실한 좌석명과 상세 위치는 입력되는지 확인한다.
7. 흐리거나 빛이 반사된 사진은 추측한 값을 채우지 않고 기존 수동 입력을 유지하는지 확인한다.
8. OCR 진행 중 좌석을 직접 입력하면 인식 완료 후에도 직접 입력한 값이 유지되는지 확인한다.
9. 사진을 빠르게 두 번 변경하면 두 번째 사진의 결과만 반영되는지 확인한다.
10. 비행기 모드에서도 OCR이 작동하고 사진과 인식 원문이 외부로 전송되지 않는지 확인한다.

## 시즌권 좌석

1. 현재 시즌 응원팀 홈경기를 선택한다.
2. 시즌권 좌석이 자동 입력되는지 확인한다.
3. 원정 경기와 다른 시즌 경기에는 자동 입력되지 않는지 확인한다.

## 다이어리 복원

1. 사진, 스티커, 텍스트와 그림을 추가하고 저장한다.
2. 앱을 종료하고 다시 실행한다.
3. 같은 티켓에서 항목의 위치, 크기, 순서와 그림이 복원되는지 확인한다.

## 다이어리 사진 추가

1. 사진 도구에서 `사진 촬영`을 선택하고 카메라 권한을 허용한다.
2. 실제 iPhone에서 촬영하면 원본 비율로 편집 화면이 열리고, 크롭 영역을 자유롭게 조절할 수 있는지 확인한다.
3. `앨범에서 선택`도 기존처럼 사진을 추가하고, 두 방법 모두 취소하면 사진이 추가되지 않는지 확인한다.

경## 다이어리 레이어 패널

1. iPhone과 iPad에서 세로·가로 속지의 레이어 패널을 연다.
2. 아이템 개수와 관계없이 패널의 위·아래 여백이 편집 영역에서 동일한지 확인한다.
3. 아이템이 많으면 패널 높이는 유지되고 내부 목록만 스크롤되는지 확인한다.

## 다이어리 내보내기

1. 실제 iPhone에서 사진, 스티커, 텍스트와 그림을 추가한 다이어리를 연다.
2. 상단 내보내기 버튼에서 `다이어리만`을 선택하고, iOS 공유 시트가 열리는지 확인한다.
3. 미리보기에 속지와 모든 꾸미기 요소가 보이고 선택 테두리, 편집 도구와 레이어 패널은 보이지 않는지 확인한다.
4. `경기 정보와 함께`를 선택하면 날짜, 시간, 경기장과 대진·점수 또는 경기 상태가 속지 위에 표시되는지 확인한다.
5. 세로·가로 속지에서 이미지가 잘리지 않고, 공유 시트를 취소해도 다이어리가 변경되지 않는지 확인한다.

## 삭제 격리

1. 사진과 다이어리가 있는 티켓을 삭제한다.
2. 삭제한 티켓이 목록에서 사라지는지 확인한다.
3. 다른 티켓의 사진과 다이어리가 그대로 열리는지 확인한다.

## 경기 기록 입력

1. 경기 기록에서 `오늘의 기록`을 열고 입력한다.
2. `먹은 메뉴 추가`를 눌러 음식 이름을 입력한다.
3. 두 입력칸이 키보드 위에 보이고, 드래그하면 키보드가 내려가는지 확인한다.
